# Paleta de colores — Perucha y Asociados

Extraída directamente de peruchayasociados.com (estilos computados de la página en vivo).

## Marca / acento
- Morado principal (botones, logo, CTA): `#70698a`
- Lavanda claro (fondos de icono, detalles): `#c4b5fd`

## Neutros
- Fondo de página: `#faf9fe`
- Fondo de sección alterna: `#f6f7fb`
- Blanco (tarjetas, header): `#ffffff`

## Texto
- Texto principal: `#1f2937`
- Texto secundario / muted: `#6b7280`

## Acento secundario (uso puntual, ej. check/éxito)
- Verde: `#22c55e` (fondo claro) / `#065f46` (texto)

## Variante oscura (confirmada en Instagram @peruchayasociados)
- Morado oscuro (fondos de slide, contraste fuerte con texto blanco): `~#3d3752`
- Se usa en redes para frases cortas de impacto (fondo morado oscuro + texto blanco grande). Útil como variante de sección destacada en la web (ej. la frase "Experiencia que sigue evolucionando" o un CTA final), sin convertirlo en el fondo general de la página.

## Uso recomendado en la web nueva
- Fondos: alternar `#faf9fe` / `#ffffff` / `#f6f7fb` entre secciones para dar ritmo sin usar color de marca de fondo.
- CTA y elementos interactivos (botones, enlaces activos, iconos de área): `#70698a`, con `#c4b5fd` como variante clara (fondos de icono, hover, badges).
- Texto: `#1f2937` para títulos y cuerpo, `#6b7280` para subtítulos y texto de apoyo.
- Verde reservado solo para estados puntuales (confirmación, check), no como color de marca.
